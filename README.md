## 🚀 Sobre mim

Sou **Jarlisson Brito**, estudante de **Ciências da Computação** e desenvolvedor web em formação, aqui do 📍 **Brasil**.

- 🤖 Meu maior projeto hoje é o **JARVIS**, um assistente de IA pessoal em Python com voz, memória e plugins
- 🌐 Construo interfaces web com **HTML, CSS e JavaScript** e back-ends simples com **Python + Flask + SQLite**
- ♿ Tenho interesse especial em **acessibilidade e inclusão digital**
- 🧮 Também gosto da parte matemática da computação: **álgebra linear e métodos numéricos**
- 🤝 Aberto a **estágio, vaga júnior, freelas e projetos colaborativos**

> 💡 *Transformando ideias em projetos através da tecnologia.*
